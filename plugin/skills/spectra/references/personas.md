# Core personas (Quick)

Skip specialists unless the user asked for Deep.

## deep-design

- **system-architect** — long-term structure, boundaries, change
- **security-expert** — abuse, authn/z, data exposure
- **pm** — scope, users, ship criteria
- **be-engineer** — implementation cost, APIs, failure modes

## decision-board

- **architect** — 2–5 year fitness, abstractions
- **pragmatist** — ship now, smallest reversible bet
- **devils-advocate** — why the leading option is wrong
- **risk-assessor** — downside, rollback, blast radius

## peer-review

- **security-auditor** — vulns, secrets, auth
- **reliability-engineer** — failure modes, ops
- **test-strategist** — coverage gaps, regressions
- **maintainability-advocate** — complexity, naming, coupling

## trust-layer

- **package-validator** — does the artifact match what was asked
- **intent-auditor** — hidden scope, extra files, surprise behavior
- **security-challenger** — adversarial read of the output
- **coherence-checker** — internal contradictions

## coherence-monitor

- **alignment-auditor** — still solving the original problem
- **contradiction-detector** — conflicting claims
- **constraint-monitor** — broken budgets, deadlines, invariants
- **devils-examiner** — the work is theater
